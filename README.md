# Верните себе рабочий день

Русскоязычный интерактивный скролл-сюжет о пяти прикладных сценариях ИИ. Посетитель выбирает 2–3 повторяющиеся задачи, получает шаблоны запросов и собирает двухнедельный план внедрения без регистрации и отправки данных на сервер.

## Локальная разработка

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`. Режим выступления доступен по адресу `http://localhost:3000/?present=1`.

## Проверка

```bash
npm run lint
npm test
PAGES_BASE_PATH=/ai-productivity-webinar npm run build:pages
```

- `npm run build` создаёт Sites/vinext-артефакт в `dist/`.
- `npm run build:pages` создаёт статический Next.js export в `out/` с `basePath` для GitHub Pages.

## Приватность

Сайт не использует backend, аналитику, формы, аккаунты или внешние API. В `localStorage` под версионным ключом сохраняются только идентификаторы выбранных сценариев; выбор можно сбросить на странице.
