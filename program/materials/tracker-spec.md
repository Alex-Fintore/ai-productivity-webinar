# Спецификация журнала трёх повторов

## Листы

### Старт

- название программы;
- краткая инструкция;
- поля участника: роль и дата начала;
- пять кандидатов на сценарии;
- оценка частоты, времени, проверяемости, цены ошибки и безопасности данных;
- формула приоритета без скрытой логики.

### Повторы

По три строки на каждый из трёх выбранных сценариев.

Поля:

- сценарий;
- номер повтора;
- дата;
- материал на входе;
- исходное время, минут;
- время с ИИ и проверкой, минут;
- экономия времени, минут;
- изменение времени, %;
- ручная правка по шкале 1–5;
- число серьёзных ошибок;
- полезность по шкале 1–5;
- что изменить в инструкции;
- решение.

### Итог

Для каждого сценария:

- среднее исходное время;
- среднее время с ИИ;
- средняя разница;
- средняя ручная правка;
- сумма серьёзных ошибок;
- средняя полезность;
- итоговое решение.

Формулы должны ссылаться на лист «Повторы». Пустые строки не должны давать
ошибки деления или ложные нули.

## Проверки ввода

- номер повтора: 1–3;
- ручная правка: 1–5;
- полезность: 1–5;
- решение: «оставить», «изменить», «отказаться»;
- время и число ошибок: неотрицательные числа.

## Визуальная система

- тёплый фон, тёмно-зелёные заголовки и киноварный акцент из презентации;
- скрытые сетки и явные границы только у смысловых блоков;
- редактируемые поля отделены от формул цветом;
- закреплённая строка заголовков на длинном листе;
- никаких декоративных диаграмм: основной результат читается из итоговой
  таблицы.
